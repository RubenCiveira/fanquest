# Documentacion del proyecto

Este directorio resume el funcionamiento de la ayuda de juego para poder entender el
proyecto y desarrollar sobre el con seguridad.

## Lectura recomendada

1. [Vision funcional](./funcional.md): que hace la app, secciones y flujos de
   usuario.
2. [Arquitectura tecnica](./tecnica.md): stack, estructura, rutas, estado,
   persistencia y despliegue.
3. [Datos y plantillas](./datos-y-plantillas.md): contenido editable, mazos,
   personajes, reglas especiales e imagenes.
4. [Flujos internos](./flujos.md): pasos tecnicos de generacion, preparacion,
   partida e impresion.
5. [Guia de desarrollo](./desarrollo.md): comandos, convenciones y puntos de
   extension habituales.
